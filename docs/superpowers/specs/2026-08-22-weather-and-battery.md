# Mac灵动岛天气与电池界面设计

## 目标

- 将当前白色、宽大的电池弹窗改成黑色紧凑面板，与灵动岛视觉一致。
- 在主页增加与日历同宽的天气模块，显示当前位置、天气、温度和湿度。
- 在设置中允许单独开关天气，并安全录入和风天气 API Host 与 API KEY。
- 日历、待办、天气组合变化时，展开的灵动岛宽度同步调整；三项全开时继续增宽。

## 已确认方案

### 天气数据

- 使用和风天气 Web API，不引入其 SDK。
- 使用系统 Core Location 获取当前经纬度。
- 请求 `GET /geo/v2/city/lookup` 获取地区名称，请求 `GET /v7/weather/now` 获取实时天气。
- API KEY 仅通过 `X-QW-Api-Key` 请求头发送。
- 每 30 分钟刷新一次；重复打开灵动岛优先复用缓存，失败后保留最后一次成功数据。
- 卡片显示“和风天气”数据来源，满足署名要求。

### 凭据安全

- API Host 和 API KEY 不写入 Swift 源码、配置文件或 Git 历史。
- 设置页提供 API Host 与 API KEY 输入框，保存到 macOS 钥匙串。
- API KEY 使用安全输入框，不在日志和错误提示中输出。

### 页面布局

- 天气卡片固定宽度 165、高度 120，与日历一致。
- 待办在与其他侧栏并列时宽 145，单独显示时宽 165。
- 主页有两个或更多侧栏时播放器宽 250；一个侧栏时沿用紧凑播放器宽度；无侧栏时沿用当前宽度。
- 展开宽度由侧栏数量和实际内容宽度计算，最低保持当前紧凑宽度；三项全开时宽度大于 640。

### 电池弹窗

- 宽度从 320 缩小为约 248，内边距和行间距同步收紧。
- 使用黑色背景、白色主文字、灰色辅助文字和低对比度分隔线。
- 保留电量、供电来源、低电量模式、充电剩余时间和系统电池设置入口。

## 错误与权限状态

- 未配置凭据：天气卡片提示前往设置配置。
- 定位未授权：显示定位权限提示，设置页可发起授权。
- 网络或接口失败：显示简短错误；如果有缓存则继续展示缓存。
- API Host 或 API KEY 无效：设置页显示验证失败，不回显密钥。

## 验收标准

- 日历、待办、天气任意开关组合不会裁切；三项全开时灵动岛明显增宽。
- 天气卡片与日历同宽，显示当前地区、天气、温度、湿度和和风天气署名。
- 凭据只存在于钥匙串，Git 差异中不包含 API KEY。
- 电池弹窗为黑色紧凑样式，所有原有操作仍可用。
- Debug 与 Release 构建通过；天气核心解析与布局计算测试通过。
